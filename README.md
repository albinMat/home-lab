# Proxmox Home Lab

This repository documents my personal home lab built to practice virtualization,
Linux administration, networking, troubleshooting, and self-hosted services.

## Hardware

- HP ProDesk 600 G1 SFF
- Intel Core i3-4160 @ 3.60 GHz
- 24 GB DDR3-1600 RAM
- 250 GB SATA SSD
- Gigabit Ethernet

## Virtualization

- Proxmox VE 9.2
- Ubuntu Server virtual machines
- Bridged networking using vmbr0

## Current Services

### Minecraft Server
- Ubuntu Server VM
- Java 21
- Fabric Minecraft 1.21.1
- Separate standard and modded servers
- Modpack management using Modrinth
- Remote access for friends using a secure tunnel

### Jellyfin
- Dedicated Ubuntu Server VM
- Jellyfin media server
- Browser-based administration
- Future external storage planned

## Administration Tools

- SSH
- SFTP / WinSCP
- Proxmox web interface
- Linux command line
