# Jellyfin Media Server

## Environment

Jellyfin runs in its own Ubuntu Server virtual machine on Proxmox.

## Purpose

The goal of this project is to learn how self-hosted web applications work
and eventually create a personal media library.

## Current Status

- Ubuntu Server installed
- Jellyfin installed
- Web administration interface accessible over the LAN
- External media storage planned

## What I Learned

- Dedicated VM design
- Linux package installation
- Service-based applications
- Browser access using an IP address and port
- Storage planning
